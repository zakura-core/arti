# Removed onion-service hosting APIs

This fork supports embedded Tor clients. It no longer provides onion-service
hosting. Connecting to public or restricted onion services remains supported;
client authentication keys retain the `keymgr` opt-in.

This inventory was generated from all-feature Rustdoc output at [b9726621](https://github.com/zakura-core/arti/tree/b9726621f74d293517190a219af1f2b92c84c10d/crates/tor-hsservice).
It preserves 622 public and crate-visible declarations, including generated
builders and getters, enum variants, fields, trait methods, aliases, constants,
and re-exports from the deleted `tor-hsservice` crate. Source links are pinned
to that revision so the definitions and their generic bounds remain reviewable.
The table omits standard blanket and synthetic auto-trait implementations.

## Additional `arti-client` API changes

- Removed features: `onion-service-service`, `hss-negotiate-extensions`, and
  `restricted-discovery`. `full` and `experimental` no longer enable hosting.
- Removed `config::onion_service` and its `OnionServiceConfig` and
  `OnionServiceConfigBuilder` re-exports.
- Removed `InertTorClient::create_onion_service` and
  `TorClient::{create_onion_service, launch_onion_service,
  launch_onion_service_with_hsid}`.
- Removed `ErrorDetail::{OnionServiceSetup, LaunchOnionService}`. These
  variants were internal by default and public with `error_detail`.
- The retained `TorClient::hs_circ_pool` and `TorClientConfig` implementation
  of `HsCircPoolConfig` now require `onion-service-client`, in place of the
  previous client-or-hosting gate; their signatures do not change. Vanguard
  configuration and its setup-error gates narrow the same way.
- The private `ClientShared::state_directory` field and hosting-only state
  initialization and C Tor service-keystore attachment code disappear.

The deleted package also loses every feature it provided: `default`, `full`,
`restricted-discovery`, `metrics`, `experimental`, `experimental-api`,
`negotiate-extensions`, and the internal `__is_experimental` marker.
