# Removed configuration-file APIs

Baseline: `dad913ec3968769976abfe1d7fd2341c93e0bb4d`.

This inventory was derived from all-feature Rustdoc JSON before and after
the deletion. It includes public and crate-visible declarations, enum
variants and fields, inherent methods, and explicit trait methods.
Synthetic auto traits and standard-library blanket implementations are
omitted; removing a type also removes those implementations.

Additional Cargo/API removals:

- `tor-config/load-config` and `arti-client/load-config` features.
- Test-only crate-visible `ConfigurationTree::get_string` helper.
- `arti_client::config::default_config_files`.
- `arti_client::config::{ConfigurationSource, ConfigurationSources, ConfigError}` re-exports.
- `tor_keymgr::config::ConfigurationSource` re-export.
- `tor_config::load::TopLevel` implementation for `arti_client::config::TorClientConfig`.

Typed builder traits and their existing paths, configuration defaults,
validation, explicit storage permissions, and programmatic
reconfiguration remain unchanged. No public or crate-visible items are added.
